# Agent 工作台 UI 重规划

## 目标

将当前“地图 + 任务侧栏 + 右侧多面板堆叠”改造成任务执行优先的工作台：地图保持主视觉，Agent 作为可收起的右侧 Dock；对话、历史、任务状态互不挤压。

## 当前证据

- 1280×720 页面中，右侧同时放置任务状态、终端日志、Agent 标题、宽度控制、24 条会话、聊天消息和输入框。
- 会话列表预览包含大量默认欢迎语和空会话，无法有效帮助用户识别历史任务。
- Cesium 导航说明默认覆盖地图主体。
- 右侧宽度滑块能改变比例，但没有收起/展开语义，窄屏时按钮和历史预览发生换行。

## 设计决策

1. 保留三块工作区：左侧任务控制、中央地图、右侧 Agent Dock。
2. Agent Dock 默认显示“对话”，历史移入独立“历史”视图；历史默认只取最近 8 条，并过滤没有用户消息的空会话。
3. Dock 支持收起；收起时地图扩展，右侧保留一个明确的展开入口。
4. 当前会话的默认欢迎语只用于展示，不作为历史预览标题；预览优先使用最近一条用户消息，没有用户消息的会话不进入历史视图。
5. 地图导航帮助默认隐藏，地图工具保持紧凑浮动入口。
6. 外部影像和精确空间元数据仍按当前安全策略固定拒绝，不在新 UI 中恢复授权复选框。

## 验收标准

- 1280×720 首屏同时看到地图、对话消息和输入框。
- 历史视图不占用对话视图的消息高度；可以切换会话并回到对话。
- Agent Dock 可以收起和重新展开；宽度保持 24%–48% 范围。
- 新打开页面不会因默认欢迎语产生可见的重复历史预览。
- 地图导航帮助不会默认覆盖地图主体。
- 现有任务确认、地图跳转、附件本地预览和安全边界测试继续通过。
